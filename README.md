🚀 Face Recognition Attendance System
A modern, biometric attendance and employee management platform powered by FastAPI, InsightFace, and OpenCV. Featuring a responsive Glassmorphic UI, this application enables frictionless employee onboarding, multi-identifier lookups, and real-time facial recognition attendance logging.

⚡ Key Features
Biometric Authentication: Face login using real-time webcam video feeds or file uploads via InsightFace embeddings.

Dual-Step Onboarding: Complete employee profile creation paired with instant facial feature vector generation.

Flexible Identification: Retrieve employee profiles seamlessly by ID, Email, or Full Name.

Attendance Engine: Real-time Check-In and Check-Out validation with persistent SQLite status logging.

Glassmorphic Interface: Clean, responsive web interface built with vanilla HTML, CSS, and WebRTC.

🛠️ Tech Stack
Backend: Python, FastAPI, SQLite, Pydantic

Computer Vision & AI: InsightFace, OpenCV, NumPy

Frontend: HTML5, CSS3, JavaScript (Fetch API & WebRTC)
